# Star Cool Service — website

Single-page website for **Star Cool Service**, AC, refrigerator and washing machine
installation, repair and maintenance in Chennai.

Live: https://starcoolservices.vercel.app/

- `index.html` — the whole site (HTML, CSS and JavaScript in one file).
  Phone, WhatsApp, service areas and reviews are configured in the
  **BUSINESS CONFIGURATION** block near the bottom of the file.
- `images/` — optimised images, logo files and the hero video.
- `robots.txt`, `sitemap.xml`, `site.webmanifest` — search engine and app metadata.
- `SEO-SETUP.md` — checklist for Google Business Profile, Search Console and listings.

No build step: Vercel serves the files as they are. Every push to `main` redeploys the site.
